# ERA Construction — İlkin məlumat anketi (demo stend)

**Word:** [`ERA-Construction-Pilot-Anket-AZ.docx`](./ERA-Construction-Pilot-Anket-AZ.docx)  
**Audience:** construction pilot / demo on real company data (AZ).  
**Regen:** `node scripts/gen-construction-pilot-intake-docx.mjs`

This is the intake questionnaire for org + satellite setup. Product follow-up: five-level estimate documentation (lokal → obyekt → toplu) + Forma-2 / payment bridges — Construction owns the ops pack; Finance owns money; bridges only, no duplicate ledgers.

Each numbered field in the Word file has a **gray hint** under the label (what we expect). Spelling uses standard AZ Latin (`tender`, not `tendər`; `imzalanmış`, not `imzalənmiş`).

---

Bu anket demo stendin sizin real məlumatlarınızla qurulması üçündür. Qısa və konkret cavab verin. Bilmirsinizsə — «yoxdur» və ya «sonra göndərəcəyəm» yazın. Excel və digər faylları anketlə birlikdə göndərə bilərsiniz.

Hər sualın altında boz izah var — nəyi yazmağınızı gözlədiyimizi göstərir. Cavabları azərbaycan və ya rus dilində yaza bilərsiniz.

## 1. Şirkət

1. Hüquqi ad (tam) — *VÖEN-də və nizamnamədə yazılan rəsmi ad.*
2. Brend / ticarət adı (əgər fərqlidirsə) — *Vizitkart / sayt adı; eynidirsə «eyni».*
3. VÖEN — *10 rəqəm.*
4. Hüquqi ünvan — *Reyestr ünvanı.*
5. Ofis ünvanı (fərqlidirsə) — *Faktiki ofis; eynidirsə «eyni».*
6. Telefon — *+994…*
7. E-poçt — *Demo üçün əsas iş e-poçtu.*
8. Sayt (varsa) — *Yoxdursa «yoxdur».*
9. Şirkətin əsas rolu: baş podratçı / alt podratçı / tikinti sifarişçisi / qarışıq — *Birini seçin və ya qısa izah.*
10. Qrupda neçə hüquqi şəxs var? VÖEN-ləri yazın — *Holdingdirsə bütün VÖEN-lər.*
11. Demo üçün bir hüquqi şəxs kifayətdir, yoxsa bir neçəsi lazımdır?
12. Uçot valyutası (adətən AZN)

## 2. Demo-da hansı hissələr lazımdır

13. Tikinti (obyekt, smeta, sahə, aktlar) — bəli / xeyr
14. Maliyyə (müqavilə, ödəniş, Forma-2 / hesablaşma) — bəli / xeyr
15. CRM (tender / satış, tikintiyə qədər) — bəli / xeyr — *«tender» latın yazılışı.*
16. Kadr / tabel — bəli / xeyr — *İş vaxtı tabeli; əməkhaqqı məcburi deyil.*
17. Demo-da neçə istifadəçi olacaq?
18. İnterfeys dili: az / ru / en (prioritet sırası)

## 3. Pilot obyektlər (1–2 real obyekt)

23. Mərhələ: layihələndirmə / tikinti / təhvil / zəmanət

## 4. Smeta və sənədlər (dövlət layihələri üçün)

35. Tam smeta paketi aparırsınızmı: lokal → obyekt → toplu (xülasə) smeta? — *Lokal / obyekt / toplu izahı Word-də.*
36. Yoxsa əsasən müqavilə smetası / bir BOQ kifayətdir? — *BOQ = iş həcmləri cədvəli.*
37. Smetaları indi harada aparırsınız: Excel / Smeta.az / 1C / digər  
38. Smeta ekspertizadan / sifarişçinin təsdiqindən keçirmi?  
39. Demo-da Forma-2 lazımdır? — *Görülən işlərin qəbul / hesablaşma sənədi.*  
40. Forma-3 lazımdır?  
41. Forma-4 — sizdə hansı sənəddir? Qısa yazın (və ya nümunə göndərin)

## 5. Sahə işləri və sənədlər
