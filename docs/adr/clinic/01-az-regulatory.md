# ERA Clinic — Azerbaijan regulatory map

## 6. Азербайджан: регуляторика и интеграции

| Тема | Что известно | Что это значит для нас |
|---|---|---|
| İcbari Tibbi Sığorta (İTS) | Агентство İTS — оператор базы данных ОМС; Положение (e-qanun.az/framework/48393) регулирует формирование базы и перечень систем, которые **должны интегрироваться** с ней, обмен — через Электронное правительство («Vahid Giriş»). [S21] | Частная клиника работает с İTS по договору; нам нужен учёт **услуг, оказанных по İTS**, отдельно от платных, и выгрузка/отчёт для возмещения. |
| e-Tabib / направления | Пациент выбирает частную клинику (из заключивших договор с İTS) в приложении e-Tabib, раздел «Göndərişlər», получает SMS-код, обратиться нужно в течение 10 рабочих дней. [S22, S23] | Регистратуре нужно поле «код/номер направления İTS», тип оплаты визита `ITS`, привязка услуг к направлению, срок действия. API e-Tabib для частных МИС публично не описан → **адаптер-интерфейс + ручной ввод** (P1). |
| Рецепты | «Rəqəmsal resept» в составе VSİS; пациенты видят рецепты в приложении «Reseptim» и в mygov. [S24, S25] | Наш рецепт должен иметь справочник лекарств (МНН/торговое), дозировку; подготовить адаптер выгрузки в Rəqəmsal resept (P1/P2 по мере доступности API). |
| e-Epikriz, e-Bülleten | Созданы в рамках VSİS (электронный эпикриз, электронный больничный). [S24] | Стационарный выписной эпикриз (H7) и больничный лист — сразу проектировать в структурированном виде, чтобы потом отдать адаптеру. |
| Стандарты | Минздрав публикует перечень стандартов: ISO/HL7 16527 (функциональная модель EHR), ISO 17523 (требования к e-рецептам), МКБ и др. [S26] | Модели данных EMR — в духе HL7/FHIR (Encounter, Observation, MedicationRequest/Administration, Condition, DocumentReference) — облегчит будущую интеграцию. |
| mygov | Пациенты видят «Ailə həkimim», «Həkim müraciətlərim», «Laborator analiz nəticələrim» в mygov. [S23] | Конкурентно нам нужен свой хороший портал пациента; потенциально — выгрузка лаб-результатов. |
| Персональные данные | Закон «О персональных данных» (упомянут в Положении İTS). [S21] | Аудит доступа к карте (у нас есть), согласия на обработку (C7), разграничение доступа врача к «своим» пациентам — проверить RBAC. |

> Всё, что связано с госинтеграциями, делаем через **порт-адаптер** в `era-clinic/src/integration/` с режимами `disabled | manual | api`, по аналогии с интеграционным слоем, который готовится для CRM (`docs/adr/satellite-integration-channels.md`). Ключи/эндпоинты — в настройках организации, не в env.
