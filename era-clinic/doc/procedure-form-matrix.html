Слой 1 — процедура → зоны / препараты

Колонки: Процедура → Зона → Грубые части тела → Препараты → Направления. Зоны = allowedSiteCodes. Правило «грубые части»: если allowlist процедуры только чипы погружения (FULL / TO-WAIST / SITZ / 4-камера) → колонка «—» (не разворачиваем coarse каталога). Если есть хоть одна анатомическая зона (Amplipuls, массаж, …) → coarse[] как в каталоге. Препараты = FO allowlist (preview). Струи Hidromasaj = hint, не S.
